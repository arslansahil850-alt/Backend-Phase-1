01

Variables: var, let, and const

Store and manage values in JavaScript.

What is a variable?

A variable is a named reference used to store a value that your program can use.

  • var is function-scoped and can be redeclared.
  • let is block-scoped and allows reassignment.
  • const is block-scoped and prevents reassignment.
Remember: Prefer const by default. Use let when reassignment is needed.

A const object can still have its properties changed. The variable binding, not the entire object, is protected from reassignment.

variables.js 
let score = 10;
score = 20;

const username = "Arslan";

const user = {
    name: "Arslan"
};

user.name = "Sahil";

console.log(score);
console.log(username);
console.log(user.name);
OUTPUT 
20
Arslan
Sahil
02

Arrow Functions

Write concise function expressions.

What is an arrow function?

An arrow function is a shorter syntax for writing a function expression.

When the function body contains a single expression, you can omit the braces and the explicit return.

Arrow functions do not have their own this binding.
functions.js 
function add(a, b) {
    return a + b;
}

const multiply = (a, b) => a * b;

const square = n => n * n;

console.log(add(5, 3));
console.log(multiply(4, 2));
console.log(square(6));
OUTPUT 
8
8
36
03

Template Literals

Build readable strings using variables.

Why use template literals?

Template literals use backticks instead of ordinary quotation marks. They allow variables and expressions to be inserted using ${...}.

They also support multiline strings.

templates.js 
const name = "Arslan";
const skill = "JavaScript";

const message =
    `My name is ${name} and I am learning ${skill}.`;

console.log(message);
OUTPUT 
My name is Arslan and I am learning JavaScript.
04

Default Parameters

Give parameters fallback values.

How do default parameters work?

A default parameter provides a value when an argument is omitted or explicitly passed as undefined.

Passing null does not trigger the default value.

defaults.js 
function greet(name = "Developer") {
    return `Hello, ${name}!`;
}

console.log(greet("Arslan"));
console.log(greet());
console.log(greet(undefined));
console.log(greet(null));
OUTPUT 
Hello, Arslan!
Hello, Developer!
Hello, Developer!
Hello, null!
