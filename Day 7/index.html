THE LESSONS

Understand the fundamentals

Learn each concept before moving to the playground.

01

What is Async?

Asynchronous operations let JavaScript handle tasks that take time without making your code wait in a blocking way. 

console.log("First");

setTimeout(() => {
    console.log("Later");
}, 1000);

console.log("Second");
Output: First → Second → Later
02

Async Functions

The async keyword declares an asynchronous function. Calling it always returns a Promise. 

async function greet() {
    return "Hello Developer";
}

greet().then(console.log);
Output: Hello Developer
03

Await Keyword

await pauses the surrounding async function until a Promise settles. It does not block the entire JavaScript application. 

const promise = Promise.resolve(100);

async function showValue() {
    const value = await promise;
    console.log(value);
}

showValue();
Output: 100
04

Try & Catch

Use try for code that may fail and catch to handle a thrown error or a rejected Promise awaited inside the block. 

try {
    throw new Error("Something failed");
} catch (error) {
    console.log(error.message);
}
Output: Something failed
05

Finally

The finally block runs after try/catch, whether the operation succeeds or fails. It is useful for cleanup and ending loading indicators. 

try {
    console.log("Working");
} catch (error) {
    console.log("Failed");
} finally {
    console.log("Finished");
}
Output: Working → Finished
06

Throw Your Own Error

Use throw new Error() when your code detects a problem that should be handled by a catch block. 

function checkAge(age) {
    if (age < 0) {
        throw new Error("Invalid age");
    }

    return "Age accepted";
}
Invalid input produces an error.
HOW IT WORKS

The async/await flow

1

Call async function

Start the asynchronous operation.

→
2

Await Promise

Wait for its result inside the function.

→
3

Handle result

Continue or catch an error.

Important distinction

async/await does not replace Promises. It provides a cleaner way to work with them. A rejected Promise awaited inside a try block can be handled by catch.

Exercise 2: Use await

Await Promise.resolve(50) inside an async function and print the result.

async function showNumber() {
    const number = await Promise.resolve(50);
    console.log(number);
}

showNumber();

Exercise 3: Catch an error

Throw an error inside try and print its message inside catch.

try {
    throw new Error("Practice error");
} catch (error) {
    console.log(error.message);
}

Exercise 4: Simulate a request

Create an async function that waits for a Promise and then prints "Data received".

const wait = ms =>
    new Promise(resolve => setTimeout(resolve, ms));

async function loadData() {
    await wait(1000);
    console.log("Data received");
}

loadData();
