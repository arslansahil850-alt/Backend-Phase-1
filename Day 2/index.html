THE FUNDAMENTALS

Learn the Concepts

Read the explanation and study the examples.

01

Array Destructuring

Extract array values into variables.

Without destructuring, you access values by their index. Destructuring lets you unpack those values directly. 

const colors = ["red", "blue", "green"];

// Traditional way
const first = colors[0];
const second = colors[1];

// Destructuring
const [a, b, c] = colors;

console.log(a); // red
console.log(b); // blue
console.log(c); // green
Remember: Array destructuring depends on position. The first variable gets the first value.
02

Object Destructuring

Extract values using property names.

const user = {
  name: "Arslan",
  age: 17,
  skill: "JavaScript"
};

const { name, skill } = user;

console.log(name);  // Arslan
console.log(skill); // JavaScript

// Rename a variable
const { name: userName } = user;
console.log(userName); // Arslan

// Set a default value
const { country = "Pakistan" } = user;
console.log(country);
Remember: Object destructuring uses property names, not the order of properties.
03

Spread Operator (...)

Expand iterable values or enumerable object properties.

// Copy an array
const original = [1, 2, 3];
const copy = [...original];

// Combine arrays
const extra = [4, 5];
const combined = [...original, ...extra];

// Copy and update an object
const profile = {
  name: "Arslan",
  skill: "HTML"
};

const updatedProfile = {
  ...profile,
  skill: "JavaScript"
};

console.log(combined);       // [1, 2, 3, 4, 5]
console.log(updatedProfile); // Updated object
Important: Spread creates a shallow copy. Nested objects are still shared unless you copy them separately.
04

Rest Parameters (...)

Collect remaining arguments into an array.

function sum(...numbers) {
  return numbers.reduce(
    (total, number) => total + number,
    0
  );
}

console.log(sum(2, 3));       // 5
console.log(sum(1, 2, 3, 4)); // 10

// Rest in destructuring
const [first, ...remaining] = [10, 20, 30, 40];

console.log(first);     // 10
console.log(remaining); // [20, 30, 40]
Remember: Rest gathers the remaining values. In function parameters, it must be the last parameter.
05

Spread vs Rest

Same three dots, different jobs.

Feature Spread Rest
Purpose Expands values Collects values
Example [...items] function fn(...args)
Common use Copying and merging Flexible arguments
!

Common Mistakes

Small syntax errors can cause disproportionately annoying problems.

  • const { name } = user; Correct for an object with a name property.
  • const [first] = items; Correct for getting the first array value.
  • function add(...numbers, tax) {} Incorrect. A rest parameter must be last.
  • const copy = { ...original }; This is a shallow copy, not a complete deep clone.
