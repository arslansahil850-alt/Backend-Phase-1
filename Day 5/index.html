CONCEPT 01

What is JSON?

JSON stands for JavaScript Object Notation. It is a text format used to exchange structured data.

JSON Example

{
  "name": "Arslan",
  "age": 18,
  "skills": ["HTML", "CSS", "JavaScript"],
  "isLearning": true
}

JSON supports strings, numbers, booleans, arrays, objects, and null.

Important JSON Rules

  • Property names must use double quotes.
  • Strings must use double quotes.
  • JSON does not allow comments.
  • JSON does not allow trailing commas.
  • JSON is text, not a JavaScript object.

Convert between JSON and JavaScript

JSON → JavaScript 
const jsonText = '{"name":"Arslan"}';

const user = JSON.parse(jsonText);

console.log(user.name);

JSON.parse() converts valid JSON text into a JavaScript value.

JavaScript → JSON 
const user = {
    name: "Arslan",
    skill: "JavaScript"
};

const jsonText = JSON.stringify(user);

console.log(jsonText);

JSON.stringify() converts a JavaScript value into JSON text.

CONCEPT 02

What is the Fetch API?

Fetch allows browser JavaScript to make HTTP requests to servers and APIs.

Your JavaScript

Requests information.

→
02

API Server

Processes the request.

→
03

Response

Returns data and a status code.

A basic Fetch request

async function getUser() {
    try {
        const response = await fetch(
            "https://jsonplaceholder.typicode.com/users/1"
        );

        if (!response.ok) {
            throw new Error("Request failed");
        }

        const user = await response.json();

        console.log(user.name);
    } catch (error) {
        console.error(error.message);
    }
}

getUser();

Understand each step

  1. fetch(url) sends an HTTP request.
  2. await waits for the response Promise.
  3. response.ok checks whether the HTTP status is successful.
  4. response.json() reads the response body and parses its JSON.
  5. try/catch handles errors from the awaited operations.
Important: Fetch normally does not reject just because a server returns an HTTP error such as 404 or 500. Check response.ok yourself. Network errors, by contrast, can reject the Fetch Promise.
