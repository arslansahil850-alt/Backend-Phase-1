JavaScript Promises

Learn how JavaScript represents future results, handles asynchronous operations, and responds to errors.

THE FUNDAMENTALS

What is a Promise?

A Promise is a JavaScript object representing the eventual success or failure of an asynchronous operation.

01

Pending

The operation has not finished yet.

Waiting
02

Fulfilled

The operation completed successfully.

Success
03

Rejected

The operation failed.

Failure
Remember: A Promise settles only once, either by fulfilling or rejecting. It cannot return to pending afterward.

CODE EXPLANATION

Create Your First Promise

Creating a Promise
const myPromise = new Promise((resolve, reject) => {
    const success = true;

    if (success) {
        resolve("Operation successful!");
    } else {
        reject(new Error("Operation failed!"));
    }
});

myPromise
    .then(result => console.log(result))
    .catch(error => console.error(error.message));

resolve()

Fulfills the Promise with a result.

reject()

Rejects the Promise with a reason, commonly an Error.

.then()

Registers a handler for fulfillment. It also returns a new Promise.

.catch()

Registers a rejection handler for errors in the Promise chain.

Chaining Promises
Promise.resolve(5)
    .then(number => number * 2)
    .then(number => number + 3)
    .then(result => console.log(result))
    .catch(error => console.error(error));

Output: 13. Each then() passes its returned value to the next handler.

Important: .then() does not mean “run this immediately after the previous line.” Promise handlers run asynchronously as part of JavaScript's microtask processing.
