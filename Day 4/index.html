JavaScript Module Fundamentals

Study the filenames carefully. Module examples involve more than one file.

01

What Is a JavaScript Module?

A JavaScript file that can share or use functionality.

A module helps you organize related code into a separate file. For example, math functions can live in math.js, while application code lives in app.js. 

project/
├── index.html
├── app.js
└── math.js
Remember: A module helps organize code. npm packages and frameworks are different concepts.
02

Named Exports

Export multiple values from one file.

File: math.js

export const pi = 3.14159;

export function add(a, b) {
    return a + b;
}

export function subtract(a, b) {
    return a - b;
}

File: app.js

import { pi, add, subtract } from "./math.js";

console.log(pi);
console.log(add(10, 5));
console.log(subtract(10, 5));
Remember: Named imports use the exported names inside curly braces. The names must match unless you use aliases.
03

Default Export

Export one main value from a module.

File: greeting.js

export default function greet(name) {
    return `Hello, ${name}!`;
}

File: app.js

import greet from "./greeting.js";

console.log(greet("Arslan"));
// Hello, Arslan!
Remember: A default import does not need curly braces. Its local name can differ from the exported function's name.
04

Import Aliases

Give an imported name a different local name.

// math.js
export function multiply(a, b) {
    return a * b;
}

// app.js
import { multiply as multiplyNumbers } from "./math.js";

console.log(multiplyNumbers(4, 5));
// 20
Remember: The as keyword changes the local import name. It does not rename the original export.
05

Import Everything

Collect named exports under one namespace.

// math.js
export const pi = 3.14159;

export function square(number) {
    return number * number;
}

// app.js
import * as math from "./math.js";

console.log(math.pi);
console.log(math.square(5));
Remember: Namespace imports collect named exports under an object-like namespace. A default export is accessed separately unless explicitly imported into that namespace.
06

Modules in Node.js

Use ES modules in backend projects.

Node.js supports ES modules. One common approach is to set "type": "module" in your project's package.json. 

{
    "type": "module"
}

Then you can use imports and exports in your JavaScript files.

// server.js
import { createServer } from "node:http";

const server = createServer((request, response) => {
    response.end("Arslan Weblab server is running!");
});

server.listen(3000, () => {
    console.log("Server running at http://localhost:3000");
});
Important: Node.js can also use CommonJS with require() and module.exports. Do not mix module systems without understanding the rules.
07

Named vs Default Exports

Know which syntax to use.

Feature Named Export Default Export
Quantity per file Multiple One default
Import syntax { add } greet
Import name Must match or use alias Can be chosen by importer
Typical use Several related utilities Main value or function

Exercise 2: Named Import

import { multiply as product } from "./math.js";

Exercise 5: Mini Project, Utility Module

// math.js
export function add(a, b) {
    return a + b;
}

export function square(number) {
    return number * number;
}

// app.js
import { add, square } from "./math.js";
