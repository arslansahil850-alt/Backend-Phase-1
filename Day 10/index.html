THE COMPLETE PICTURE

Phase 1 Revision Roadmap

Review each concept, understand its purpose, and mark it complete.

01

Modern JavaScript

Template literals, let/const, arrow functions, default parameters, and cleaner syntax.

const name = "Arslan";

const greet = (person = "Developer") => {
    return `Hello, ${person}!`;
};

console.log(greet(name));

Remember: Template literals use backticks. Default parameters provide values when arguments are omitted or undefined.

02

Destructuring, Spread & Rest

Extract values, copy data, combine arrays, and collect function arguments.

const user = {
    name: "Arslan",
    role: "Developer"
};

const { name, role } = user;

const first = [1, 2];
const second = [...first, 3];

function total(...numbers) {
    return numbers.reduce((sum, n) => sum + n, 0);
}

Remember: Destructuring extracts values. Spread expands values. Rest collects values.

03

Array Methods

Transform, filter, search, and calculate data without writing unnecessary loops.

const numbers = [1, 2, 3, 4, 5];

const doubled = numbers.map(n => n * 2);
const even = numbers.filter(n => n % 2 === 0);
const sum = numbers.reduce((total, n) => total + n, 0);

console.log(doubled);
console.log(even);
console.log(sum);

Remember: map transforms, filter selects, and reduce combines values into one result.

04

JavaScript Modules

Split code into reusable files using exports and imports.

// math.js
export const add = (a, b) => a + b;

// app.js
import { add } from "./math.js";

console.log(add(5, 3));

Remember: Export makes functionality available to other modules. Import brings it into another file.

05

JSON & Fetch API

Exchange data with APIs and convert JSON responses into JavaScript values.

async function loadUser() {
    const response = await fetch(
        "https://jsonplaceholder.typicode.com/users/1"
    );

    if (!response.ok) {
        throw new Error("Request failed");
    }

    const user = await response.json();
    console.log(user.name);
}

loadUser().catch(console.error);

Remember: fetch sends a request. response.json() reads and parses the JSON body. Check response.ok because HTTP errors do not automatically reject fetch.

06

Promises

Understand operations that finish successfully or fail later.

const task = new Promise((resolve, reject) => {
    const success = true;

    if (success) {
        resolve("Task completed");
    } else {
        reject(new Error("Task failed"));
    }
});

task
    .then(result => console.log(result))
    .catch(error => console.error(error));

Remember: A Promise can be pending, fulfilled, or rejected. Use then for results and catch for failures.

07

Async/Await & Error Handling

Write asynchronous code in a readable style and handle failures.

async function getData() {
    try {
        const response = await fetch(
            "https://jsonplaceholder.typicode.com/posts/1"
        );

        if (!response.ok) {
            throw new Error("Could not load data");
        }

        const data = await response.json();
        console.log(data);
    } catch (error) {
        console.error(error.message);
    }
}

getData();

Remember: await pauses the surrounding async function until a Promise settles. try/catch handles thrown errors and rejected awaits.

08

HTTP Fundamentals

Learn how clients and servers communicate through requests and responses.

GET     /users       // Read users
POST    /users       // Create a user
PATCH   /users/1     // Update part of a user
DELETE  /users/1     // Delete a user

// A response contains:
// Status code, headers, and possibly a body.

Remember: GET reads, POST commonly creates, PATCH partially updates, and DELETE removes a resource. Status codes describe the result.

09

Node.js & Core Modules

Run JavaScript outside the browser and use built-in tools to work with files and paths.

// app.js
const path = require("node:path");
const fs = require("node:fs");

const filePath = path.join(__dirname, "notes.txt");

fs.writeFileSync(filePath, "Learning Node.js");

const content = fs.readFileSync(filePath, "utf8");
console.log(content);

Remember: Node.js runs JavaScript outside the browser. fs handles files, path builds paths safely, and npm manages project packages.

10

Express & Your First Server

Use a framework to create routes and respond to HTTP requests.

// First install Express:
// npm install express

const express = require("express");
const app = express();

app.use(express.json());

app.get("/", (req, res) => {
    res.send("My backend is running!");
});

app.get("/api/user", (req, res) => {
    res.json({ name: "Arslan", role: "Developer" });
});

app.listen(3000, () => {
    console.log("Server running on port 3000");
});

Remember: A route connects an HTTP method and URL to a handler. req contains request information; res sends the response.
