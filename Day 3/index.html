LEARN BY EXAMPLE

JavaScript Array Methods

Read the code, understand the output, and then try it yourself.

01

forEach()

Perform an action for every array element.

Use forEach() when you want to perform an action for each item. It does not create a new array from the callback results. 

const names = ["Arslan", "Ali", "Ahmed"];

names.forEach((name, index) => {
    console.log(index, name);
});

// Output:
// 0 Arslan
// 1 Ali
// 2 Ahmed
Remember: Use forEach() for actions, such as displaying items. Use map() when you need a new array.
02

map()

Transform every element into a new array.

const numbers = [1, 2, 3, 4];

const squares = numbers.map(number => number * number);

console.log(squares);
// [1, 4, 9, 16]

console.log(numbers);
// [1, 2, 3, 4]
Remember: map() returns a new array containing the callback's return values.
03

filter()

Create an array containing elements that pass a condition.

const ages = [12, 18, 15, 22, 30];

const adults = ages.filter(age => age >= 18);

console.log(adults);
// [18, 22, 30]
Remember: filter() returns all matching elements. If nothing matches, it returns an empty array.
04

find() and findIndex()

Find the first matching element or its position.

const numbers = [10, 25, 30, 45];

const found = numbers.find(number => number > 20);
const position = numbers.findIndex(number => number > 20);

console.log(found);
// 25

console.log(position);
// 1

console.log(numbers.find(number => number > 100));
// undefined

console.log(numbers.findIndex(number => number > 100));
// -1
Remember: find() returns the first matching element. findIndex() returns its index. When no match exists, they return undefined and -1 respectively.
05

reduce()

Combine array values into one result.

const prices = [100, 200, 300, 400];

const total = prices.reduce(
    (sum, price) => sum + price,
    0
);

console.log(total);
// 1000
Remember: The second argument, 0 here, is the initial accumulator value. Providing an initial value is especially useful when the array might be empty.
06

some() and every()

Check whether some or all elements meet a condition.

const scores = [45, 60, 75, 90];

const hasHighScore = scores.some(score => score >= 80);
const allPassed = scores.every(score => score >= 40);

console.log(hasHighScore);
// true

console.log(allPassed);
// true
Remember: some() checks whether at least one element matches. every() checks whether all elements match.
07

sort()

Sort array elements in a chosen order.

const numbers = [100, 5, 25, 10];

const ascending = [...numbers].sort((a, b) => a - b);
const descending = [...numbers].sort((a, b) => b - a);

console.log(ascending);
// [5, 10, 25, 100]

console.log(descending);
// [100, 25, 10, 5]

console.log(numbers);
// [100, 5, 25, 10]
Remember: sort() changes the original array. Copy it first with [...numbers] if you want to preserve it. Without a comparator, numbers are sorted lexicographically after being converted to strings.
08

Quick Comparison

Choose the correct method for the job.

Method Purpose Returns
forEach() Perform an action per item undefined
map() Transform each item New array
filter() Select matching items New array
find() Find first matching item Element or undefined
findIndex() Find first matching position Index or -1
reduce() Accumulate a result Single result
some() Check if any match Boolean
every() Check if all match Boolean
sort() Sort elements Same array, sorted

PRACTICE MAKES PROGRESS

Five Coding Exercises

Attempt each exercise before revealing its solution.

Exercise 1: Transform with map()

Convert every number to its square.

const numbers = [2, 3, 4, 5];
const squares = numbers.map(number => number ** 2);
console.log(squares); // [4, 9, 16, 25]
Exercise 2: Filter with filter()

Return only numbers greater than 10.

const numbers = [4, 12, 7, 20, 9, 15];
const result = numbers.filter(number => number > 10);
console.log(result); // [12, 20, 15]
Exercise 3: Find an item

Find the first user whose age is at least 18.

const users = [
    { name: "Ali", age: 16 },
    { name: "Sara", age: 20 },
    { name: "Ahmed", age: 25 }
];
const user = users.find(person => person.age >= 18);
console.log(user); // { name: "Sara", age: 20 }
Exercise 4: Calculate with reduce()

Calculate the total cost of these items.

const prices = [250, 150, 300, 100];
const total = prices.reduce((sum, price) => sum + price, 0);
console.log(total); // 800
Exercise 5: Mini Project, Shopping Cart Total

Calculate the total price of all products in a shopping cart.

const cart = [
    { name: "Keyboard", price: 2500 },
    { name: "Mouse", price: 1200 },
    { name: "Headphones", price: 3500 }
];
const total = cart.reduce(
    (sum, product) => sum + product.price,
    0
);

console.log("Cart total:", total);
// Cart total: 7200
